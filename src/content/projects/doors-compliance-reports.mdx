## Overview

As Assistant Data Engineer at Key Direction Limited (Tai Wo Hau, March 2025–March 2026), I replaced hand-built compliance reports with a repeatable pipeline.

## What it does

- Parses DOORS Next XML into schema-driven Excel workbooks with openpyxl through an internal API
- Collects and exports the source files with Playwright and pywin32
- Assembles the submission PDF with PyMuPDF
- Produces a repeatable, traceable deliverable for compliance audit

## Related work

I also optimized complex SQL queries that aggregate and validate large, multi-source datasets for automated reporting, and supported RAMS (Reliability, Availability, Maintainability, Safety) and system assurance so traceability stayed aligned with safety-critical regulatory frameworks.
