## The pipeline

I am a software engineer at Shui On Building Contractors Limited in Tai Kok Tsui, in a role that started in April 2026. The piece of work I keep coming back to is a Python automation pipeline that integrates SOAP APIs for PLC controllers.

Before the pipeline, configuring those controllers took about two weeks. After it, the same configuration takes about two minutes.

## Around that pipeline

The same role includes three other threads that sit next to the automation work.

**Least privilege.** I ran an internal cybersecurity audit by provisioning, modifying, and auditing user accounts, access levels, and permissions tables. That covered centralized and distributed environments, on both Windows and Linux, with the principle of least privilege as the rule.

**Physical to virtual.** I directed an end-to-end asset modernization and physical-to-virtual migration so secure access management systems kept working. The target was zero operational downtime.

**Documentation that tracks the code.** With the test and commissioning team, I standardized technical documentation in a Docusaurus pipeline. It is secured with Cloudflare Zero Trust and managed in GitHub, so the docs stay aligned with real-time code deployments and with the compliance those deployments have to meet.
